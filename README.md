# AI-Based-Rotten-Fruit-Sorting-System
 Developed a real-time fruit sorting system using YOLOv8 object detection and a ResNet18-based CNN classifier, achieving 96% classification accuracy in identifying fresh and rotten fruits.  Integrated the ML pipeline with an Arduino Uno via UART serial communication to control a conveyor belt, servo-based ejector arm, and I2C LCD display.
